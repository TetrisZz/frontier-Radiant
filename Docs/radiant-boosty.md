# Подписка Boosty → Discord → Radiant Sector

Уровень «Уважаемый член общества» (500 ₽/месяц) открывает существующее донатное снаряжение. `HomUplinkRadio100` выдаёт `BaseHomUplinkRadio100` со 100 кристаллами при появлении игрока на роли, в списке снаряжения которой есть этот набор. Покупки работают в текущем раунде. Здесь нет ежемесячного кошелька или отдельного начисления кристаллов.

У игроков с подтверждённым донатным доступом ник в OOC окрашен в `#9370D8`; текст сообщения не меняется. Существующий админский цвет имеет приоритет. После снятия доступа новые сообщения отправляются без донатного цвета; уже отправленные сообщения сохраняют прежнее оформление. LOOC и IC-чат не меняются.

В сообщениях AHelp донатный ник также имеет цвет `#9370D8`. Для администраторов с правом NameColor используется их цвет из `setadminooc`, включая сообщения с настроенным скрытием настоящего ника. Цвет обновляется для новых сообщений без переподключения. Для ответов через Discord остаётся стандартный админский цвет: у webhook-отправителя нет подтверждённого игрового аккаунта, чтобы загрузить персональную настройку.

## Настройка владельцем

1. В Discord создайте роль «Уважаемый член общества». Разрешите этой роли доступ к закрытому чату. Не выдавайте эту роль через самоназначение или обычные роли за активность: сервер считает её подтверждением подписки.
2. В настройках аккаунта автора Boosty подключите официального бота Boosty к вашему Discord. Расположите роль бота выше донатной роли, чтобы он мог управлять ею.
3. В редактировании уровня «Уважаемый член общества» включите «Доступ в Discord» и выберите эту донатную роль. Подписчики должны привязать свой Discord в настройках Boosty и вступить в ваш Discord.
4. Для собственного игрового бота создайте приложение в Discord Developer Portal (или используйте существующего бота сборки). На странице Bot включите Server Members Intent и Message Content Intent: существующий DiscordLink запрашивает оба. Пригласите бота в ваш Discord. Для проверки роли ему не нужны права администратора или управления ролями. Получение и отправка личных сообщений должны быть доступны.
5. Включите режим разработчика Discord и скопируйте ID сервера и донатной роли. Настройте серверный TOML:

```toml
[discord]
token = "TOKEN_IGROVOGO_BOTA"
guild_id = "ID_DISCORD_SERVERA"
prefix = "!"
show_online = true

[radiant]
supporter_discord_role = "ID_DONATNOY_ROLI"
supporter_enabled = true
```

`discord.token` — токен собственного игрового бота, а не официального бота Boosty. Секретный конфиг не добавляйте в Git. После настройки перезапустите сервер; клиент и сервер должны использовать обновлённую сборку.

Бот автоматически показывает «Онлайн сервера: N» в своей активности. Считаются все подключённые игроки, включая лобби и призраков. Изменения отправляются не чаще раза в 15 секунд; после переподключения бота статус восстанавливается. Дополнительный Discord-канал или права администратора не нужны. `discord.show_online` включён по умолчанию; `show_online = false` убирает активность с онлайном.

До включения `radiant.supporter_enabled` сохраняются прежние ручные разблокировки через 100 часов `JobBoxer`. После включения донатное снаряжение проверяет Discord-роль; ранее добавленные часы не удаляются, но больше не открывают эти донатные наборы. Подготовьте роли и сообщите нынешним подписчикам о привязке перед переключением.

## Для игрока

1. Купите подписку на https://boosty.to/radiant_sector, привяжите Discord в настройках Boosty и вступите в Discord сервера.
2. Подключитесь к игре. В игровой консоли выполните `supporterlink`. Откроется окно: нажмите «Копировать команду», чтобы скопировать `!link КОД` целиком. Код не копируется в буфер автоматически; повторная команда заменяет прежнее окно и отменяет старый код.
3. Оставаясь подключённым, отправьте выданную команду `!link КОД` **в личные сообщения игровому боту**. Код действует 10 минут и используется один раз. Новый код отменяет предыдущий.
4. Выполните `supporterstatus` в игре. После подтверждения роли заново откройте выбор снаряжения и выберите магазин на доступной роли.

Привязка сохраняется в игровой базе данных. Один Discord-аккаунт может быть привязан только к одному игровому аккаунту. Смена игрового ника не требует повторной привязки: хранится UUID.

## Проверки и эксплуатация

Подтверждённый доступ хранится в базе вместе с привязкой. При входе игрока запросов в Discord нет, проверки каждые 5 минут также нет. События выдачи/снятия роли, вступления и выхода из Discord обновляют базу и доступ подключённого игрока; изменения сохраняются и для игроков офлайн. При первой привязке проверяется уже существующая роль.

После запуска, восстановления соединения бота и изменения настроек выполняется сверка всех привязанных аккаунтов: она исправляет события, пропущенные во время выключенного сервера. Только при ошибке синхронизации выполняются повторные попытки раз в минуту. При сбое Discord сохранённый доступ остаётся до успешной сверки; новые неподтверждённые подписки не открываются. Следите за доступностью бота. Уже выданный магазин остаётся в раунде. Историю привязок и изменения доступа сервер пишет в обычный лог.

Дату окончания оплаты игра не получает: окончание подписки отражается снятием роли официальным ботом Boosty. Если Boosty не снял роль, игровой бот сам не может определить окончание подписки.

Для исправления ошибочной привязки администратор с правом Permissions выполняет ` UUID_ИГРОВОГО_АККАУНТА`, после чего игрок может привязаться заново. Самостоятельная многократная переброска подписки между игровыми аккаунтами недоступна.

Перед запуском проверьте на тестовой подписке: выдачу роли официальным ботом Boosty, привязку, доступ к магазину после переподключения, отказ при привязке того же Discord к второму игровому аккаунту и закрытие доступа после снятия роли. Проверку реального окончания оплаченного периода Boosty нужно провести отдельно: игра видит Discord-роль, а не дату оплаты.
