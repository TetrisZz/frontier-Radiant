## Фиксы совместимости Radiant

- Типы с `[Dependency]` и `[DataDefinition]` сделаны `partial`;
  с полей зависимостей убран `readonly` для новых генераторов.
- Автоматические свойства полей данных получили необходимые сеттеры.
- Сохранён серверный режим существующих медицинских тестов
  через `PoolManager.ServerOnly.cs`.
- Эти тесты используют `SharedMapSystem` и координаты сущности карты
  вместо удалённого `IMapManager`.
- CI упаковки учитывает изменения `.slnx`.
- Шесть вызовов `string.Join` в панели взаимодействий переведены
  на явные массивы: C# 14 иначе создавал `InlineArrayAsReadOnlySpan`,
  который RT281 ILVerify отвергал при подключении клиента.
- Добавлена проверка песочницы без запуска всего контента, чтобы
  ошибки прототипов и спрайтов не мешали выявлять ошибки IL.
  Переменная `RADIANT_SANDBOX_ASSEMBLY_DIRECTORY` позволяет проверять
  фактические Release/FullRelease DLL.

Песочница и ILVerify остаются включёнными.
Новые игровые системы, контент, спрайты и переводы из `fix`
не перенесены. В частности, новая генетика и её исправления
остаются вместе с самой генетикой, которой в `master` ещё нет.

## Проверка

Нужен SDK .NET 10. После клонирования:

```powershell
git submodule update --init --recursive
dotnet build SpaceStation14.slnx
dotnet test Content.Tests/Content.Tests.csproj --no-build --no-restore
dotnet test Content.IntegrationTests/Content.IntegrationTests.csproj --no-build --no-restore --filter 'FullyQualifiedName~SandboxTest.AssembliesWithoutContentStartup'
```

Проверено в этой изолированной ветке на SDK 10.0.110:

- Полная сборка `SpaceStation14.slnx`: 0 ошибок.
- Модульные тесты: 441 пройден, 1 пропущен.
- Два существующих медицинских теста и Debug-песочница: 3 пройдены.
- Сборка клиента с `-c Release -p:FullRelease=true`: 0 ошибок.
- Песочница с DLL этой Release/FullRelease-сборки: 1 пройден.
- `git diff --check`: без ошибок.

Компиляция выдаёт предупреждения существующих зависимостей и анализаторов;
они не подавлялись. Полный набор интеграционных тестов и подключение
к удалённому серверу в рамках выделения ветки не проверялись.
Локальные TRX-отчёты находятся в `bin/engine-pr-test-results`
и не включены в Git.
